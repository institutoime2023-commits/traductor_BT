# TRADUCTOR Android V0.4 - Whisper.cpp + ML Kit + Voz TTS + Bluetooth

Aplicación Android para reconocimiento local en inglés (Whisper.cpp v1.7.6), traducción local al español (Google ML Kit) y reproducción de voz en español por altavoz o auriculares/gafas Bluetooth (Android TextToSpeech), optimizada para Xiaomi Redmi 12C.
